# Giridharen Goguladhevan — Portfolio

A minimalist, high-performance portfolio website built with **React**, **Vite**, **Framer Motion**, and a custom dark/light design system.

## 🚀 Features

- **Minimalist Aesthetic**: Dark & Light mode toggle with customizable CSS tokens and glassmorphism styling.
- **Fluid Animations**: Smooth scroll-triggered entrance transitions powered by Framer Motion.
- **Responsive Layout**: Customized 2-column Hero section with profile avatar and adaptive navigation.
- **Structured Resume Sections**: Hero, About, Skills, Experience, Projects, Education, and Contact.

## 🛠 Tech Stack

- **Frontend Framework**: React 19 + Vite 8
- **Animations**: Framer Motion
- **Icons**: React Icons (Feather Icons)
- **Styling**: Vanilla CSS with custom properties & glassmorphism

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
